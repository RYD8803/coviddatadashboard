# COVID Data Dashboard

## Overview

This presentation introduces an interactive Shiny application designed to explore global COVID-19 trends.

### Features

- Cumulative cases and deaths visualization
- Country and WHO region filtering
- Time-based analysis
- Interactive Plotly graphs

### How to Use

- Select time range using date filter
- Switch between Country and WHO Region view
- View cumulative cases and deaths
- Interactive tooltips using Plotly
- Customize plot appearance (titles, axes)
